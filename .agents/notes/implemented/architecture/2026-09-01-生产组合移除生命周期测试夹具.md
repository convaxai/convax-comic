# 生产组合移除生命周期测试夹具

## 决策

从 `default` profile 删除 `@convax/test-consumer`，并删除该测试专用插件包。`appRuntime` 继续作为产品 Host 服务存在，但不再为了证明 Cordis 的通用注入语义而挂载无产品消费者的插件。

## 理由

`@convax/test-consumer` 的诊断快照只由自身测试读取，生产代码没有消费者；插件随 default profile 常驻后会启动 5ms 计时器。Cordis 的等待、provider 卸载/恢复等生命周期行为已由 SQLite、CanvasStore、Canvas Builtins 等真实产品依赖链的 headless 测试覆盖，不需要把证明夹具放入生产组合。

`appRuntime` 的重复 provider 拒绝行为移动到 runtime 包自身测试，避免随夹具包删除而失去该服务的唯一性回归覆盖。

## 边界

- `compatibility` profile 不变，仍保持上游 Client 零覆盖。
- `auth-fence`、command guard、安全 overlay、权限、服务名和产品数据目录不变。
- default 的预期组合差异只有删除 `app-test-consumer` 一行；不增加替代 wrapper、timer 或兼容层。
- 本决策实现 GitHub Issue #4。

## 验收

- immutable install、runtime 单测、profile gate、dump-config gate通过。
- default dump 与改动前相比只删除 `app-test-consumer`；compatibility dump 逐字不变。
- 根 `yarn check` 与 `yarn smoke:upstream` 最终 headless 回归均通过。
