# 启动状态与会话模块身份

## 现象

桌面启动时会短暂显示错误语气的页面；进入 Renderer 后，Agent 面板又可能
无法正常新建会话。这两个现象容易被误判为“没有配置模型 Key”。

## 根因与决策

- 监督器把正常的运行时等待阶段也传给 `failurePageUrl`。等待不是失败，因此
  单独提供无按钮、带进度提示的 `loadingPageUrl`；只有子进程退出、超时等
  真实故障才显示重试、日志和退出动作。
- Yarn `nmHoistingLimits: workspaces` 让产品插件解析到了另一份 DSH 包实例。
  Cordis service/事件依赖模块身份，`agent-presets` 必须从当前 `$DSH_HOME`
  profile 的 `package.json` 出发解析并动态加载运行时同一份
  `@deepseek-ai/dsh-agent-presets`，避免跨实例注册失效。
- 不绕过上游 credentials。创建/选择本地 session 不需要模型 Key；只有发送
  请求并调用模型 provider 时才需要有效凭证。右侧仍复用上游官方 conversation
  与 workspace/session service。

## 验收

- 状态页单测分别断言 loading 与 failure 的标题、动作和 HTML 转义边界。
- `agent-presets` 的 build、typecheck、test 通过，真实 Electron 启动不再出现
  preset 注册错误。
- 无 Key 的真实应用中可以建立并选中空白 session；发送模型请求仍按上游
  onboarding/credentials 流程要求配置 Key。
